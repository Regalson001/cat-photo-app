# Cat Photo App 🐈

An interactive web application showcasing cat photo galleries, forms, and lists, built during my frontend software development training.

## 🚀 Features
* **Semantic HTML Structure:** Structured using standard HTML5 tags like headings, sections, images, forms, and input fields.
* **Interactive Form Elements:** Includes radio buttons, checkboxes, and input fields for user interaction (e.g., submit cat photos, select cat personality traits).
* **Media Integration:** Displays optimized external images with descriptive alt text and clickable image links.

## 🛠️ Built With
* **HTML5**
* **Git & GitHub**
